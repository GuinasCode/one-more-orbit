## Taglines

## Short Description

One More Orbit is a fast-restart arcade survival game where you boost away from a gravity core, dodge rotating mines, and chase one more clean lap.

## Feature Bullets

- One-button control scheme that works on keyboard, mouse, and touch
- Deterministic hazard patterns that reward learning and route planning
- Sector unlock progression stub for continued runs beyond the first clear
- Browser-first build with instant restart flow and compact session length
